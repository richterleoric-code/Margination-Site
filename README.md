# Margination
SEE THE WORDS. STAY IN THE STORY.

Paste a passage, highlight a moment, and Margination draws it as a storybook illustration. Save favorites to a personal library.

This is a plain website (no install, no server). It works on GitHub Pages.

## Put it online (GitHub Pages)
1. Create a new GitHub repository.
2. Click **Add file > Upload files** and drag in everything that is INSIDE this folder (`index.html` must end up at the top level of the repo). Click **Commit changes**.
3. Go to **Settings > Pages**. Under "Build and deployment" choose **Deploy from a branch**, pick branch **main** and folder **/ (root)**, then **Save**.
4. Wait 1 to 2 minutes and open the link GitHub shows (https://YOUR-NAME.github.io/REPO-NAME/).

## Use it
1. Get a free Gemini API key at https://aistudio.google.com/apikey
2. Open the site, go to **Workspace**, paste the key in the pink box, and click **Save key**. (It is saved only in your browser, never on GitHub.)
3. Click a sample (or paste your own text), highlight a sentence, and press **Illustrate**.

## Notes
- Images are made by Google Gemini ("Nano Banana"). The free tier has limits.
- The library is stored in your browser only. Clearing site data deletes it.
- The illustration on the home page is a hand-drawn demo, not AI.
